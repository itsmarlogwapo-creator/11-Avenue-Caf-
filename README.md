### ✨ Features
- 🏠 **Dashboard** - Benta Today, Best Seller, Low Stock Alert
- 📦 **Stocks / Inventory** - Add, Edit, Delete, Search, Sort, Picture
- 🛒 **Sell Button** - Bawas stock, dagdag sa benta
- 🛍️ **Customer Order** - Add to Cart, Checkout
- 🧾 **Receipt** - May resibo na pwede i-print
- 🌙 **Dark Mode** - Pang-gabi vibes
- 👤 **Profile** - Owner info
- ← **Back Button** - Page 3 → Page 2 → Page 1
